✨ Features

A magical AI assistant that does more than just talk

🗣️

Real-Time Voice

Live audio streaming via Gemini Native Audio — not turn-based. Continuous conversation with natural interruptions, in 8 languages.

👀

Screen Vision

The genie can see your screen through desktop capture. It observes, understands, and acts on what it sees — powered by Gemini Computer Use.

🧞

3D Holographic Avatar

A Three.js-powered 3D genie with lip-synced speech, mood expressions, eye contact, and magical smoke effects. Male and female avatars.

⚡

221+ Automation Actions

Control Finder, Notes, Messages, Calendar, VS Code, Safari, Music, Terminal, and more through 221 deterministic macOS automation functions.

🔍

Google Search Grounding

Real-time factual information via Google Search grounding. No hallucination — the genie always checks the latest data before answering.

🧠

Encrypted Memory

Persistent memory that learns your preferences, remembers your name, and improves across sessions. All AES-256-GCM encrypted locally.
